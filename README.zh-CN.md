LEExtractor 面向文献调研与研究证据整理，围绕一个连续的工作流程设计：输入研究问题，找到相关文献，查看关键发现，再回到证据原文和来源。

**让每一条发现，都有可回看的出处。**

> 当前 README 展示产品概念与拟议工作流程。可用版本、安装方式及功能实现状态将在首次发布时补充。

## 从一个问题开始

```text
具身智能：视觉语言动作模型与机器人泛化
```

一个研究主题，可以延伸出一组需要核实的问题：视觉语言动作（VLA）模型如何将视觉信息与语言指令转化为机器人动作？面对新物体、新任务和新环境时如何评估泛化？不同研究的机器人平台、训练数据与成功率能否直接比较？

LEExtractor 的设计目标，是将相关文献、关键发现与证据出处放在同一条阅读路径中。

<p align="center">
  <img src="docs/assets/leextractor-workflow-4k.png" alt="四步概念流程：提出研究问题、检索相关文献、阅读关键发现、回到原始来源核实证据。" width="100%">
</p>

| 步骤 | 你要做的事 | 概念设计中的呈现 |
| --- | --- | --- |
| **01 · 提问** | 输入研究主题或具体问题 | 简洁的输入框与高级选项入口 |
| **02 · 检索** | 发起文献检索 | 显示当前处理阶段与进度 |
| **03 · 阅读** | 浏览相关研究并展开条目 | 文献标题、年份、主题与关键发现 |
| **04 · 核实** | 查看证据和来源 | 证据原文与来源入口，并预留筛选、导出操作 |

## 核心体验

以下为目标能力；实现进度见[路线图](#roadmap)。

### 围绕研究问题检索

从自然语言描述开始，逐步明确研究对象、方法与关注点。将检索条件保留在工作流程中，便于调整问题、扩大范围或缩小结果集。

### 在同一处阅读发现与证据

结果条目围绕“这篇研究做了什么、发现了什么、依据在哪里”组织。概要帮助定位相关研究，证据入口帮助核对原文。

### 看见文献处理进展

用明确的阶段说明与处理计数展示进度。处理失败、无法取得全文等状态应单独呈现，便于判断本次结果的覆盖范围。

### 为后续整理保留来源

筛选与导出的设计目标，是让文献元数据、提取内容和出处一起进入后续工作。具体格式与字段将在可用版本中说明。

## 开始使用

目前可通过顶部产品预览和工作流程图了解设计中的使用体验。在线体验、安装包与源码运行说明将在对应版本开放后加入本节。

### 第一次探索的建议路径

1. **提出一个明确的问题。** 写出研究对象、关注方法和希望了解的结果。
2. **检查相关文献。** 优先查看研究对象、年份与方法是否符合需求。
3. **展开关键发现。** 将概要与证据原文对照阅读。
4. **回到原始来源。** 核对研究条件、评价指标与结论适用范围。
5. **整理需要保留的条目。** 导出功能开放后，同时保留出处信息。

### 可以从这些问题开始

```text
视觉语言动作（VLA）模型如何提升机器人对新物体、新任务和新环境的泛化能力？

比较机器人操作研究中端到端 VLA 与分层规划方法的训练数据、任务设置和评价指标。

哪些研究在真实机器人上验证了长程任务能力？区分仿真与实机结果，并标出支持结论的原文证据。
```

## 证据与来源

为便于后续核查，拟议结果结构将区分以下内容：

| 信息 | 用途 |
| --- | --- |
| 文献元数据 | 标题、作者、年份，以及可取得的 DOI 或原始链接 |
| 关键发现 | 对研究内容的整理与概括 |
| 证据原文 | 支持该项概括的原文片段 |
| 来源定位 | 可取得的章节、页码或其他定位信息 |
| 材料范围 | 标明依据是元数据、摘要还是全文 |
| 处理状态 | 标记缺失字段、未取得材料及失败条目 |

不同研究的结果需要结合数据集、实验条件和评价方法解释。用于论文、报告或正式引用时，应回到原始文献核实。

## 数据处理

发布版本将在本节说明检索问题、文献内容和生成结果如何处理，包括：

- 哪些步骤在本地执行，哪些步骤调用外部服务。
- 向文献数据源或模型服务发送哪些内容。
- 是否保存历史记录、日志和上传文件，以及如何删除。
- 哪些调用可能产生第三方服务费用。

## 参与贡献

欢迎从实际研究任务出发，帮助改进 LEExtractor：

- **分享研究场景：** 描述研究问题、希望得到的结果与当前整理难点。
- **改进交互：** 反馈输入、进度、证据阅读与来源跳转中的问题。
- **核对提取结果：** 提供可公开分享的原文片段、期望结果与复现步骤。
- **完善文档与代码：** 为安装流程、错误提示、测试和示例提交改进。

提交问题时，请附上版本、操作步骤、预期结果与实际结果，并移除密钥和不宜公开的文献内容。

## 常见问题

<details>
<summary><strong>现在可以直接使用吗？</strong></summary>

本页展示概念设计。可运行版本与体验入口将在“开始使用”中公布。

</details>

<details>
<summary><strong>只适用于具身智能研究吗？</strong></summary>

具身智能与机器人泛化用于展示研究流程。具体学科覆盖取决于后续接入的数据源和检索、提取能力。

</details>

<details>
<summary><strong>检索到文献就代表可以读取全文吗？</strong></summary>

全文可用性取决于原始来源和访问条件。结果应标明实际取得的材料范围，以便区分摘要分析与全文分析。

</details>

<details>
<summary><strong>如何报告不准确的提取结果？</strong></summary>

请提供研究问题、文献标识、相关原文、当前提取结果与期望修正，帮助复现并判断问题来自检索、材料获取还是内容提取。

</details>
