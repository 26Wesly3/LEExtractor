# LEExtractor 演示短片脚本 · 45 秒

> 用途：比赛申报页 / 评审观看 / 答辩开场 / 公众号与视频号。
> 规格：1920×1080，30 或 60 fps，H.264；竖版 1080×1920 见 §6。
> 主张：不是"再做一个搜索框"，而是"从一句研究方向，到可核查的证据链"。
> 口径：全部画面来自当前构建（v3.2 四阶段工作区）；不出现虚构数据、不出现未实现的功能。

## 2. 逐镜执行卡

### 镜 1 · 痛点（不需要真名实姓）
- 素材来源：任意数据库检索页、读书时留下的 PDF 书签、满排标签页。**不要**用别人的论文标题或未公开项目名。
- 建议只露两类画面：标签页条（可打码）、文献列表滚动。不出现姓名、单位、邮箱。
- 备选拍法：手机拍桌面（打印纸 + 记号笔圈红），2 秒，更有现场感。

### 镜 2 · 首页亮相
1. 新开一个干净标签页，`ctrl+shift+b` 隐藏书签栏。
2. 打开 `http://127.0.0.1:8000/`（对外版本用 `https://leextractor.duckdns.org`）。
3. 停留 1.5 s，让大字 "LEExtractor" 和"惟学无际，际于天地，点击开始探索"读完，再点击进入。

### 镜 3 · 从问题到文献（核心镜头，占全片 1/3）
1. 入口页停在「从哪一步开始」，镜头从两张卡片（从研究方向开始 / 从已有文献开始）扫过，点「输入研究方向」。
2. 输入 **大语言模型幻觉的检测与缓解**（实测能返回真实英文文献；别用长句，见 §5）。
3. 点「AI 增强」（灰字提示"将把题名与摘要等元数据发送给配置的模型服务"），再点「开始发现核心文献」。
4. 录到进度条"正在检索来源 …%""正在完善排序"，以及结束时的"已获得初步结果"。
5. 等列表出现后，缓慢向下滚 2 屏，让 3–4 条题目和来源标签（openalex / arxiv）在画面里停住。
6. 若想展示"中文进、英文出"，切回「研究起点」：那里有"研究意图预览"和"实际检索式"（各来源的英文 query），停留 1.5 s——这是全片最有说服力的一帧。

### 镜 4 · 判断与脉络
1. 在核心文献页依次点第 1 条的「标记核心」、第 2 条的「相关」、第 3 条的「排除」；每点一次停 0.6 s。
2. 切「研究脉络」：时间线（1905→2026 的年份分布）+「检索集内活跃方向」。
3. 不足 30 篇时会出现"关系数据不足，暂不给出分支结论"——**这是产品诚实的地方，不要剪掉**，它反而能作为"不编结论"的证据。

### 镜 5 · 证据回看
1. 点第 1 条「查看详情」：综合排序分、摘要原文、DOI、被引次数、内部引用代理指标、折叠的「排序依据」。
2. 点 DOI 旁的框（不必真打开，打开新标签会打断节奏；要真跳转就放 1 s 再回来）。
3. 切「研究洞察」：优先阅读列表 +「依据与结论」里的 事实 / 推断 两种标签。停留 2 s。

### 镜 6 · 收尾
1. 点「导出」，让格式菜单（RIS / BibTeX / CSV / 证据包 / PRISMA）完整出现 1.5 s；**不要真下载**。
2. 回首页，叠尾板：`LEExtractor — 证据留下，判断由你` + 域名 + 二维码（0.9 s 内出现，停留 3 s）。

## 3. 录制前清单（按顺序做，10 分钟）

- [ ] 先**彩排一次**完整检索，确认能返回 ≥30 篇；把结果页留在这个项目里（我已建好「研究方向项目」，见 §5）。
- [ ] 浏览器：单窗口、单标签、100% 缩放、隐藏书签栏与扩展图标；关掉微信/钉钉通知。
- [ ] 系统：开"专注助手"，屏幕录制 1920×1080，60 fps，录制鼠标光标。
- [ ] 准备两个项目：一个已跑完（用于镜 4/5/6 的稳定画面），一个新建（用于镜 3 的真实进度条）。
- [ ] 录屏软件：OBS Studio（最稳）或 Windows `Win+Alt+R`；剪辑用剪映专业版。
- [ ] 麦克风：**旁白单独录**（不要边操作边配），安静房间，离麦 15 cm。
- [ ] 网络：开录前 `curl -I https://api.openalex.org` 确认可达；失败就改录"已有结果"的项目。
- [ ] 隐私：清空地址栏历史下拉、关掉个人项目列表、隐藏域名里的个人标识。
- [ ] 素材命名：`01-pain.mp4`、`02-home.mp4` … `06-end.mp4`，一条镜头一个文件。

## 4. 剪辑与包装

- **节奏**：镜 3 的等待用 4× 变速；其余镜头 1.0–1.1×。全片不出现 >2 s 的静止画面。
- **光标**：加 8 px 高亮圈；点击时 0.2 s 的缩放脉冲。剪映自带"光标高亮"或录制软件自带。
- **字幕**：思源黑体 / 苹方，字号 42–48，白字 + 40% 黑底，底部安全区 120 px；一行 ≤ 14 字，不换行。
- **转场**：除镜 2 的白闪外一律硬切；不要花哨转场，评审看的是产品。
- **BGM**：无版权轻电子，-22 dB；旁白 -6 dB；不要卡点，保持克制。
- **尾板**：3 s，含 logo、域名、二维码、一行 Slogan。二维码指向线上演示地址。
- **导出**：H.264、1080p、CRF 20、AAC 192 kbps；另出一份 ≤10 MB 的 GIF 版留在 README。

## 5. 实测风险与备选（2026-10-17 在本机实测）

| 现象 | 原因 | 录制时怎么做 |
|---|---|---|
| 基础模式 + 28 字长句 → **0 篇**，提示"全部来源均已正常返回，且确实没有匹配文献" | 基础模式不调用模型，中文长句直接当检索词发给 OpenAlex/arXiv，匹配不到 | 用「AI 增强」+ **短**中文方向（如"大语言模型幻觉的检测与缓解"） |
| AI 增强 + 短句 → 返回真实英文文献（openalex / arxiv，含 DOI 与被引次数） | 意图解析把中文翻成各库英文检索式 | 这就是正式录制的路径；彩排时先跑一遍确认 |
| 检索要几十秒，可能触发 45 s 窗口上限 | 多来源轮转 + 扩展轮 | 变速压缩；或录"已跑完"的项目，只补拍进度条 |
| 部分来源失败时页面提示"已获取部分文献，部分来源暂不可用" | 限流 / 网络 | **保留这句**，它是可信度的来源；不要剪成"全部成功" |
| 「研究脉络」在篇数少时显示"关系数据不足" | 关系边不足阈值 | 保留，或在篇数 ≥30 的项目里录 |

**已备好的演示项目**：`研究方向项目`（e7d4b959…）已用"大语言模型幻觉的检测与缓解"跑出真实结果，可直接用于镜 4/5/6；镜 3 另建新项目重跑一次即可。

## 7. 文案备选

**开头（三选一）**
1. 查完 40 篇，脉络还是一团？
2. 你不是不会搜，是搜完不知道信哪条。
3. 一个方向，200 篇论文，从哪读起？

**结尾（三选一）**
1. 证据留下，判断由你。
2. 不替你下结论，只把证据留下。
3. 从问题出发，走到可核查的证据。
