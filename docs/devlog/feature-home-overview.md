# DevLog：首页「运行概况 + 项目里程碑」区块（含统计接口）

分支：`feature/v0.9.13`（工作树 `_ui_audit/v0913_cloud`）｜基线：`f9f77d2`
范围：首页展示 + 必要的统计接口；**算法与性能优化不在本次范围**。

## 1. 目标

在首页「功能介绍」之后、「最近项目」之前新增展示区块：

- **上：运行概况**（四项真实指标）——项目上线日期、网页点击次数、搜索运行次数、共检索得文献；
- **下：项目里程碑**——纵向时间线，最新在上，已完成与后续计划分开；
- 视觉参照 OpenAlex 首页：白底、黑色大字、灰色说明、细分隔线、宽留白、少量蓝色链接；
- 沿用现有 Vue / Vuetify / 中英切换 / 设计令牌，不引入大型依赖。

## 2. 数据来源与统计口径（关键）

| 指标 | 来源 | 口径与保证 |
|---|---|---|
| 项目上线日期 | 持久化配置 `stats.json: launch_date`，取值顺序：显式传入 → `LEEXTRACTOR_LAUNCH_DATE` → 已持久化值 → 默认 `2026-10-12` | **首次写盘即固化，重启不归零**；不使用进程/容器启动时间；只提供日期时只算天数，不编造小时分钟。UI 另用小字显示"本次进程已连续运行"，与"上线至今"明确区分 |
| 网页点击次数 | 持久化计数 `home_views` | **首页访问量 PV**，非独立访客；自首次计数起记录 `counting_since` |
| （子项）检索入口点击 | 持久化计数 `search_entry_clicks` | 首页主视觉入口 + "开始检索"按钮的点击；与检索任务数、检索成功次数分别统计 |
| 搜索运行次数 | 任务记录中 `kind == "search"` 的累计条数 | 服务端即时汇总，无前端上报、无额外埋点 |
| 共检索得文献 | 各项目语料去重后的合计（`corpus_papers`） | 服务端即时汇总 |

**防重复累计**：客户端每次页面进入生成一个 `entry_id`（`crypto.randomUUID`，回退随机串），服务端在 6 小时窗口内对同一 `entry_id` 只计一次（进程内定长去重环，4096 条上限）。组件重渲染、SSE 重连都不会重复计数。

**空状态**：某个指标尚未开始计数时返回 `count: null`，前端显示"—"，**不显示 0、不编造历史数据**。

**失败不阻塞**：写盘失败只把 `persisted` 置为 false 并保留内存计数；读/写异常一律不外抛。前端所有统计调用 `.catch(()=>null)`，统计接口 503 时首页照常渲染、检索入口照常可用（有测试覆盖）。

## 3. 实现

**后端**

- 新增 `litsearch/web/stats.py`：`StatsStore`——单个小 JSON（`data 根/stats.json`）+ 原子写（复用 `repository.atomic_json`）+ 线程锁 + 定长去重环；损坏文件按项目既有约定备份为 `stats.json.corrupt-<ts>.bak` 后重新计数。
- `litsearch/web/api.py`：新增 `StatsEventInput` 模型；`stats_payload()` 汇总四项；端点
  `GET /api/stats`（只读）、`POST /api/stats/home-view`、`POST /api/stats/search-entry-click`、
  `GET /api/stats/stream`（SSE 实时推送，`?limit=N` 可限定帧数便于验证与受限客户端，最多 16 条并发流）。
- SSE 每 2 秒推送一次真实快照（只读内存，不读盘），前端据此做"即时滚动更新"；断开由浏览器自动重连，失败不影响页面。

**前端**

- 新增 `web/src/stats.js`：首屏读取 + 两个计数上报 + `subscribeStats()`（EventSource，失败安静降级）+ `pageEntryId()`。
- 新增 `web/src/milestones.js`：里程碑集中维护（日期 / 状态 / 中英标题 / 一句话说明 / 可选详情）。
- 新增 `web/src/HomeOverview.vue`：四列数字条（大数字 → 标签 → 细分隔线 → 灰说明）+ 纵向里程碑（`<details>` 展开真实详情、已完成/后续计划分色）。数字变化时用 rAF 做滚动动画，**首帧直接落位**避免每次进首页从 0 跳字，尊重"减少动态效果"。
- `web/src/App.vue`：区块插到特征介绍与"最近项目"之间；首页主视觉入口与"开始检索"按钮各上报一次检索入口点击。
- `web/src/styles.css`：新增 `.overview-band/.stat-strip/.stat/.milestone*`；≤1023px 两列、≤599px 单列。

## 5. 风险与已知限制

1. **部署环境需可写数据目录**：不可写时计数只在内存，重启归零并标记 `persisted=false`（有测试；部署侧需保证卷可写）。
2. **搜索运行次数与共检索得文献是"当前记录"口径**：前者统计磁盘上保留的 search 任务记录，后者统计当前语料；历史被清理时数值会变化，UI 已按此措辞说明。
3. **SSE 并发流上限 16**：超出返回 503，前端退回首屏快照（不轮询）。
4. 极端情况下同一用户跨进程重启可能被重复计一次（去重环在进程内）；累计值与上线日期仍在磁盘，不受影响。
5. 移动端：≤1023px 两列、≤599px 单列规则已就位并通过规则核验；真机移动端截图受"封面高度 100svh"影响未能直接截到该区块（另：封面字标在 390px 下的右侧裁切为**既有**问题，不属于本次改动）。
