# Web 界面与后端整合（v0.9.7）

## 版本基线

后端使用 GitHub master 的 v0.9.5，界面参考群里 v0.9.6 UI 包。原型中的 `LED` 静态样例没有进入运行代码，界面请求本机 `/api`。保留首页字符鹰、字体、版式和工作流程，采用 Vue 3 / Vuetify 实现交互，FastAPI 复用 `LiteratureReviewWorkflow` 等现有算法。

## 启动与开发

Windows 使用根目录「启动Web版.bat」，其他环境安装 `python -m pip install -e ".[web]" -c constraints.txt` 后运行 `python -m litsearch.web --port 8000`。默认访问 http://127.0.0.1:8000，交互式接口说明在 `/docs`。API 与生产界面共用端口，不需要跨域配置。

前端源码位于 `web`；开发时运行 `npm ci`、`npm run dev`，同时在 8000 端口启动后端。开发代理转发 `/api`。构建后运行根目录 `python scripts/sync_web_assets.py`，同步 `web/dist` 到 Python 包的静态资源，供 wheel 安装使用。完整安装说明见 [README.dev.md](../README.dev.md)。

## 页面映射

| 页面 | 实际接口及行为 |
| --- | --- |
| 首页 | 读取最近项目；创建隔离演示项目或进入检索 |
| 检索 | 查询规划、明确年份范围、scoping/systematic 后台任务 |
| 结果 | 服务器分页与筛选、全语料 facets、种子选择 |
| 文献详情 | 元数据、发现轨迹、评分上下文、人工决定 |
| 扩展 | 所选种子雪球扩展、恢复待重试种子、BC/CC 相似检索 |
| 研究版图 | 后端聚类、时间分布、覆盖缺口、引文/派生关系和真实路径 |
| 候选问题 | 现有问题生成器返回的问题、来源及证据标识 |
| 综述筛选 | PRISMA 队列/计数、人工筛选、标定、开放全文获取 |
| 导出 | CSV、RIS、BibTeX、会话、PRISMA 与证据包的受控下载 |
| 项目 | 列表、保存、会话导入；导入创建独立项目 |
| 设置 | 数据源配置状态、凭据更新、语言及减少动效 |

## 接口与状态约束

- 创建/导入项目使用 `/api/projects`、`/api/projects/import`；演示项目使用 `/api/demo/projects`，模拟标记贯穿页面和导出。
- 读写项目使用 UUID；文献 `paper_key` 是 canonical ID 的 SHA-256，由服务端生成，支持包含特殊字符的原始标识。
- 所有修改状态的操作携带 `expected_revision`。旧页面返回 409，要求刷新后重试。每个项目最多有一个活跃任务，活跃期间其他修改被拒绝。
- 检索、扩展、相似和下载返回 202 与 `job_id`，使用 `/api/jobs/{job_id}` 查询，`/cancel` 请求取消。任务只报告阶段与计数，不伪造完成百分比。
- 共享的现有 HTTP 统计属于进程级状态，检索任务全局串行执行。全程 transport guard 限制真实请求尝试数，分页、回退、重试和下载都消耗预算，缓存命中不计网络请求。
- 取消在页面/重试/论文间协作生效，已开始的单次 HTTP 请求仍等待其超时。重启后未结束的任务标记为中断，已保存的项目检查点保留。
- 评分上下文与评分一同传出；语料/查询变化使旧标定不再有效。provider 原始计数与去重后记录数分开，PRISMA record/report 不声称是独立研究数。
- 获取失败记录 `retrieval_attempted` / `retrieval_failure_reason`，不自动排除；全文纳入要求人工读过确认。派生相似关系和真实引文边分开统计。

## 存储、配置与发布

默认数据目录 `.web-data`，可用 `--data-dir` 指定。项目、任务、缓存、下载与导出保存在该目录内，采用原子写入。损坏文件保留原文件并计入诊断，不阻止其他有效项目启动。

配置通过环境变量或本机设置持久化。浏览器读取配置只得到已配置布尔值，提交凭据后清空输入；诊断、导出和接口错误隐藏已知密钥及凭据字段。受控下载使用随机 file ID，接口不接受任意磁盘路径。

当前服务面向本机单用户，不包含账号认证、CSRF 防护或公网多租户权限。默认仅绑定 127.0.0.1。发布白名单包括源码、构建文件、启动脚本和本版文档，排除密钥、项目数据、缓存和 node_modules；包内逐文件 SHA-256 与包外整体校验值可复核。

## 保留的限制

语义向量检索、RRF、自动全文综述、研究创新性评分、GROBID 和 Zotero 同步没有在此版本实现。雪球低产停止是启发式，不是检索穷尽证明。演示文献无法下载真实全文。语料图为可读性展示最多 48 个节点、160 条边，完整关系仍由接口与证据包保存。真实来源的限流、凭据和开放获取权限需要在比赛使用环境实测。
